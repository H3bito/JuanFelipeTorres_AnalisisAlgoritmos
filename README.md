# Curso de Análisis de Algoritmos

Repositorio correspondiente al curso de Análisis de Algoritmos.
En este repositorio se almacenarán los laboratorios, ejercicios de clase
y herramientas de medición utilizadas durante el semestre.

## Estructura del repositorio

- `laboratorios/`: contiene los cinco informes de laboratorio evaluativos.
- `ejercicios-clase/`: contiene los ejercicios y actividades realizadas durante las sesiones prácticas.
- `benchmarks/`: contiene scripts para medir tiempos de ejecución y generar gráficas.
- `README.md`: contiene la documentación general del repositorio.
- `.gitignore`: especifica los archivos y carpetas que no deben ser versionados.

## Objetivos

Este repositorio se utilizará para practicar el control de versiones con Git
y GitHub, además de organizar y entregar los trabajos realizados durante el curso.

Entre los principales objetivos se encuentran:

- Mantener organizado el código desarrollado durante el semestre.
- Documentar los laboratorios realizados.
- Utilizar Git para controlar los cambios del proyecto.
- Sincronizar el repositorio local con GitHub.

## Comandos básicos

Algunos de los comandos de Git utilizados durante el curso son:

```bash
git status
git add .
git commit -m "Descripción del cambio"
git push origin main
```
