Semana 02 — Entorno de trabajo en Python

Se creó un entorno virtual en la raíz del repositorio usando python -m venv venv.
El entorno se activó desde PowerShell con .\venv\Scripts\Activate.ps1.
Se instaló matplotlib dentro del entorno virtual mediante pip install matplotlib.
Las dependencias instaladas se registraron con pip freeze > requirements.txt.
Para reproducir el entorno, se debe crear nuevamente el entorno virtual y activarlo.
Luego se instalan las dependencias con pip install -r requirements.txt.
Los ejercicios de esta semana son refactor_pep8.py y clasificador_anios.py.
